# 🛍️ Customer Shopping Behaviour Analysis & Dashboard

## 📖 Project Overview

The **Customer Shopping Behaviour Analysis & Dashboard** project is an end-to-end Business Intelligence solution that analyzes customer purchasing patterns using **Python (Jupyter Notebook)**, **MySQL**, and **Power BI**. The project demonstrates the complete data analytics workflow—from data preprocessing and database management to interactive dashboard development.

The dashboard provides valuable insights into customer demographics, shopping preferences, product categories, payment methods, seasonal trends, and purchase behavior, enabling businesses to make informed decisions.

---

## 🎯 Objectives

* Analyze customer shopping behavior and purchasing trends.
* Clean and preprocess raw data using Python.
* Store and manage data efficiently in MySQL.
* Perform SQL queries for business analysis.
* Develop an interactive dashboard using Power BI.
* Generate meaningful business insights through data visualization.
